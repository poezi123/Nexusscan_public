# NexusScan

NexusScan is a Python-based cybersecurity toolkit for **security research, network analysis, OSINT, and authorized penetration testing**.
![Nexusscan-Logo](assets/logo.png)
## Features

* Port Scanner
* Packet Sniffer
* IP / MAC Mapper
* CVE Lookup
* XSS Scanner
* SQL Injection Scanner
* SQLMap Integration
* Wireless Security Tools
* OSINT Tools
* Exploit Research
* RSA Utilities
* Password Generator

## Installation

```bash
git clone https://github.com/poezi123/Nexusscan_public.git
cd NexusScan
sudo python3 install.py
```

Some network features require administrator/root privileges.

## Requirements

* Python 3
* Scapy
* Requests
* Colorama
* PyCryptodome

Some modules require additional external tools such as SQLMap, Aircrack-ng or SearchSploit.
